# Contributing

Start with an observable failure. Include a fictional or fully sanitized input, the skill revision, the output, and the rule you expected it to follow. State whether the example came from an actual model run or is a manually constructed case.

For a change, explain the smallest correction and the behavior that should remain unchanged. Run `python3 tools/check.py`. Changing an example to make the checker pass is not evidence that the skill improved.

Preserve fixed headings, invocation gates, authorization boundaries, evidence states, and relative references unless the change explicitly addresses that contract. Keep English, Chinese, and Japanese introductions consistent. Runtime instructions may retain their original language.

Do not submit work conversations, personal performance information, client details, unpublished project names, credentials, machine paths, or internal URLs. Use invented examples with an explicit fictional label.

Document third-party origins and redistribution rights before adding material. Preserve original notices. Unchanged third-party imports and changes made only to qualify an import for this collection are outside the selection policy.

Contributions must be material you have the right to submit under this repository's MIT license. A pull request does not authorize publication of someone else's confidential material.
