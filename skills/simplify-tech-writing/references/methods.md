# 实用方法

以下是本技能自主编写的技术写作适配方法，不是标准规则的逐条摘录或译本。按当前材料选择相关方法，不把它们全部强加给每次改写。

**名称与词性**：先使用用户/领域给定的准确术语。长名称首次写全称，需要重复时定义简称，避免多个对象共用同一个简称。不要临时把名词动词化而让读者不知道具体动作，也不要以空泛名词替代动作；成熟领域用法及标识符优先保留。拼写风格遵守项目要求；未指定时保持一致，不自动把英式拼写改成美式。

**动词与时间**：在不改变时序、状态和责任的前提下减少冗长动词结构。完成时、进行时、分词或 -ing 形式并非普通英语禁用形式；它们表达的“已完成”“仍在进行”、条件或用途不能被删掉。看不清 -ing 短语修饰谁时，写出主体、条件或用途，不能猜测。短语动词意义不清时采用明确动词或解释；熟悉且准确的表达不必替换。

**指代与关系**：代词可能指向多个对象时，重复明确名称；this/“这”可能指向相反状态时，写明实际条件与结果。with 可能表达工具、伴随、属性或条件；先确定关系再改结构。冠词和指示词帮助读者识别已有对象与新对象，不靠省略它们缩短英文。that 有助于划清从句边界时保留或补入；不强制中文套用英文冠词和从句结构。

**描述与指令**：解释系统行为时陈述事实；要求读者操作时明确动作。混合文档中把必需动作放在步骤或相应指令中，不将建议改成必须，不将系统自动行为改成让用户手动执行。段落聚焦一个主题，先交代关键关系，再展开必要背景与细节。

**标点与补充信息**：标点应明确逻辑和修饰范围。复杂分号句可以拆开，但保留转折、因果和条件；不全面禁止分号。连字符可帮助英文修饰词成组，但不擅改术语、命令或代码。括号适合补充解释、简称和引用，不用于隐藏必要条件、限值或安全动作；条目、图示和步骤编号引用必须保持对应。

**其他英文表达**：不根据跨语言拼写或外观相似推断词义；不确定时核对上下文或提问。面向不熟悉缩写的读者，展开 e.g. 为举例、i.e. 为解释，etc. 为开放集合，不能把例子变成完整清单。采用合适的中性角色称谓，不改动事实身份或必要医学语境。所有格含义不明时写清所属关系；不要为自然语气推断谁拥有日志、设备或结果。

## 根据具体语义选词

同一个笼统动作词，可能分别指测量、观察、确认或运行测试。先从材料中确定动作和对象，不能为使指令具体而猜测操作。替代项词性或语义不同，改句子结构比机械换词更可靠。完成后对照条件、否定、执行主体、数量/单位、时间、结果与不确定性。

清空缓存、消除告警与清晰说明是不同动作；关闭连接不等于关闭服务器。优先保留准确的领域术语。无法从材料确定动作时保留原意或询问，不凭一个词猜出操作。
